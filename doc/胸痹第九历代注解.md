## 一、东汉书源

### 1. 张仲景《金匮要略》原文

**条文**("胸痹心痛短气病脉证治第九"):

- 师曰:夫脉当取太过不及,阳微阴弦,即胸痹而痛,所以然者,责其极虚也。今阳虚知在上焦,所以胸痹、心痛者,以其阴弦故也。
- 胸痹之病,喘息咳唾,胸背痛,短气,寸口脉沉而迟,关上小紧数,栝蒌薤白白酒汤主之。
- 胸痹不得卧,心痛彻背者,栝蒌薤白半夏汤主之。
- 胸痹心中痞,留气结在胸,胸满,胁下逆抢心,枳实薤白桂枝汤主之;人参汤亦主之。
- **胸痹,胸中气塞,短气,茯苓杏仁甘草汤主之,橘枳姜汤亦主之。**
- 胸痹缓急者,薏苡附子散主之。
- 心中痞,诸逆,心悬痛,桂枝生姜枳实汤主之。
- 心痛彻背,背痛彻心,乌头赤石脂丸主之。

**关键校勘**(唐宗海《金匮要略浅注补正》TypeID=767):

- 橘枳姜汤方后引《肘后》《千金》云:治胸痹,胸中(■如满),噎塞习习如痒,喉中涩,唾燥沫。

**TypeID 锚点**:

- TypeID=125 ID 9353 (汉·张仲景,无校注本,完整原文)
- TypeID=1294 ID 198779 "胸痹短气六" (宋·林亿/孙奇/高保衡校正本,含"胸痹短气六"章)

## 五、核心反查路径(可复现 SQL)

```sql
-- 1. 找所有含"茯苓杏仁甘草汤"或"橘枳姜汤"的 TypeID
SELECT DISTINCT TypeID
FROM zysjllsj
WHERE NeiRong LIKE '%茯苓杏仁甘草汤%'
   OR NeiRong LIKE '%橘枳姜汤%'
   OR NeiRong LIKE '%橘枳生姜汤%';

-- 2. 每个 TypeID 的元数据(取第一条)
SELECT TypeID, BiaoTi
FROM zysjllsj
WHERE ID = (
    SELECT MIN(ID) FROM zysjllsj s2 WHERE s2.TypeID = s1.TypeID
)
ORDER BY TypeID;

-- 3. 找具体章节
SELECT TypeID, ID, BiaoTi
FROM zysjllsj
WHERE NeiRong LIKE '%茯苓杏仁甘草汤%'
ORDER BY TypeID, ID;
```

## 心法

**胸痹六方虽并列,论争只有三条——何时用、为何同存、杏仁何义。** 17 医家 / 26 TypeID 全覆盖,固化进 3 条论争的横向对比,胜过把章节重复堆砌。

- **论争 1(何时用)**:水盛于气用茯苓汤,气盛于水用橘枳汤 —— 何梦瑶、陈修园、周扬俊、高学山、张璐 5 家同义不同措辞
- **论争 2(为何并列)**:一疏肺气一疏胃气 —— 张璐;反方吉益东洞疑非古方
- **论争 3(杏仁何义)**:不是散结是下气 —— 周岩、黄元御、楼英 3 家同指
