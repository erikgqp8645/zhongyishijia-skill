## 二、医林独啸斋中医世家核心定位(原文金句 · 行号引用)

### 2.1 仲景原方两条(东汉源头)

> **【原文1·狼牙汤证】**「少阴脉滑而数者,阴中即生疮,阴中蚀疮烂者,狼牙汤洗之。」(`full_transcript.md` line 192562 / 黄元御《长沙药解》zysjllsj TypeID=1294 line 198943)

> **黄元御注**:「手少阴脉动神门,足少阴脉动太溪。此**少阴脉,即尺中也**。尺脉滑而数者,**水寒土湿,生气不遂,木郁于水而生下热也**。前阴者,肾肝之所司,**木郁下热,阴中即生疮**。阴中疮蚀肌肉而溃烂者,**狼牙汤洗之,泻其湿热也**。」(zysjllsj TypeID=1294 line 198943)

> **【原文2·蛇床子散证】**「妇人阴寒,温中坐药,蛇床子散主之。」(`金匮要略·妇人杂病`)

> **邹澍注《本经疏证》**:「少阴脉滑而数,**热结下部也**。治用**野狼牙煮汤**,缠箸如茧,浸汤沥阴中,日四遍,以解毒杀虫。但用一味,以取专功。盖此证**多患于嫠寡**(寡妇)。证必**咳逆经闭,骨蒸寒热**。凡见颊赤,中有白斑,下唇红中白点,**皆阴蚀之候**。」(zysjllsj TypeID=983 line 98365)

→ **仲景原方定位**:**一寒一温、一洗一坐**——狼牙汤外洗泻湿热(湿热下注型),蛇床子散坐药温阴寒(寒湿凝滞型)。

### 2.2 阴疮三等说(陈实功《外科正宗》原文)

> **陈实功《外科正宗》卷九**(zysjllsj TypeID=852 line 157989,完整原文):
> 「夫阴疮者,大概有三等:**一者湿阴疮;二者妒精疮;三者阴蚀疮,又曰下疳疮**。
> 盖湿疮由**肾经虚弱,风湿相搏**,邪气乘之,搔痒成疮,浸淫汗出,状如疥疮者是也;
> 妒精者,由**壮年精气盈满,久旷房室**,阴上生疮,赤肿作害,烦闷痒痛者是也;
> 阴蚀疮者,由**肾脏虚邪,热结下焦,经络痞涩,气血不行**,或**房劳洗浴不洁**,以致生疮,隐忍不医, 肿尤甚,由疮在里,措手无方,疼痛注闷,或小便如淋,阴丸肿痛是也。或经十数日,溃烂血脓,肌肉侵蚀,或血出不止,以成下疳。」

→ **这是中医外科对阴疮病因的最经典三分法**,至今仍是临床分类的根基。

### 2.3 七情郁火 + 湿热下注说(陈实功/薛己)

> **陈实功《外科正宗》卷九**(zysjllsj TypeID=647 line 122166,完整原文):
> 「**阴疮论第三十九** 妇人阴疮,乃**七情郁火伤损肝脾、湿热下注**为患。其形固多不一,总由邪火所化也。」

> **薛己《校注妇人良方》卷八**(zysjllsj TypeID=915 line 161862,完整原文):
> 「诊其少阴之脉,滑而数者,阴中生疮也。前证乃**七情郁火,伤损肝脾,湿热下注**。其外证阴中出如蛇、如菌,或如鸡冠状,或生疮湿痒,或溃烂出水,或肿闷坠痛。其内证体倦内热,经候不调,或饮食无味,晡热发热,胸胁不利,小便痞胀,或赤白带下,小水淋涩。」

### 2.4 虫蚀学说(陈良甫《妇人良方》)

> **陈良甫**(zysjllsj TypeID=670 line 128110,完整原文):
> 「阴疮者,由**三虫或九虫**动作侵蚀所为也。诸虫在人肠胃之间,脏腑调和,血气充实,不能为害。若劳伤经络,肠胃虚损,则动作侵蚀于阴经者,或痒或痛,重则生疮。」

> **巢元方《诸病源候论·虚劳阴疮候》**(zysjllsj TypeID=623 line 108558):
> 「肾荣于阴器,肾气虚,不能制津液,则汗湿,虚则为风邪所乘,邪客腠理,而正气不泄,邪正相干,在于皮肤,故痒。**搔之则生疮**。」

### 2.5 运气属寒说(《医学纲目》)

> **《医学纲目·妇人部》**(zysjllsj TypeID=570 line 102263):
> 「妇人阴疮,**运气∶阴疮皆属寒**。经云∶**太阳之胜,阴中乃疡,隐曲不利,治以苦热**是也。」

→ **运气与病机结合的视角**:阴疮表象为热,本质多为「寒湿 → 木郁 → 下焦生热」的传变过程,治法当「以苦热」(用热药散寒、苦药燥湿)。

## 三、5 大病机分类(中医世家体系)

按临床实战频次 + corpus 证据数量,阴疮分为 5 大病机:

### 3.1 病机 1:湿热下注(占阴疮 40%,最常见)

- **核心特征**:阴部红肿热痛、溃烂流黄水、心烦易怒、口苦尿黄、舌红苔黄腻、脉滑数
- **代表方**:**龙胆泻肝汤** / 萆薢渗湿汤 / 凉肾汤 / 加味四物汤
- **辨证要点**:`龙胆泻肝汤`(《疡科选粹》卷四)「**肝经湿热,或囊痈便毒,下疳悬痈,肿焮作痛,小便涩滞,或妇人阴疮痒痛,或男子阴挺肿胀,或出脓水**」
- **本草溯源**:黄柏(《别录》)+ 龙胆草(《本经》)—— 清热燥湿,泻肝胆实火
- **仲景原文对应**:狼牙汤证(湿热偏盛)

### 3.2 病机 2:虫蚀蕴毒(占 25%,阴疮三等之最重)

- **核心特征**:溃烂如虫蚀、脓血淋漓、疼痛剧烈、阴器几尽、脉滑数
- **代表方**:**五味消毒饮** / 大豆甘草汤 / 补心汤 / 蒲黄散 / 一擦光
- **辨证要点**:`补心汤`(《世医得效方》卷十五)「妇人阴中生疮,或痛或痒,如虫行状,**淋沥脓汁,阴蚀几尽,名曰蠹疮**」
- **本草溯源**:狼牙(《本经》)+ 苦参(《本草纲目》)+ 硫黄(《本经》「主妇人阴蚀、疽痔恶血」)+ 雄黄(《本经》)—— 解毒杀虫
- **仲景原文对应**:阴中蚀疮烂者(狼牙汤)

### 3.3 病机 3:寒湿凝滞 / 阴寒(占 10%)

- **核心特征**:阴中冷凉、带下清稀、瘙痒、舌淡苔白、脉沉迟
- **代表方**:**蛇床子散**(坐药)/ 茴香散 / 真武汤 / 阳和汤
- **辨证要点**:「**妇人阴寒,温中坐药,蛇床子散主之**」(《金匮》)
- **本草溯源**:蛇床子(《本经》)+ 硫黄(《本经》)—— 温经散寒、燥湿止痒
- **仲景原文对应**:阴寒(蛇床子散证)

### 3.4 病机 4:气血两虚 / 中气下陷(占 15%,久溃型)

- **核心特征**:久溃不敛、肉芽灰暗、神疲乏力、腰膝酸软、阴部坠胀、脉弱
- **代表方**:**补中益气汤** + 龙胆泻肝汤(早晚分服)/ 十全大补汤 / 托里消毒散 / **回阳生肌散** / **黄连甘乳膏**
- **辨证要点**:`回阳生肌散`(《赵炳南临床经验集》)「回阳生肌,止痛收敛。治结核性溃疡、慢性顽固性溃疡及**属于阴疮久不收口者**」
- **本草溯源**:黄耆(《本经》「**痘疹阴疮,则当以黄耆为君,人参为臣**」)+ 当归(《唐本草》)—— 益气养血、托毒生肌

### 3.5 病机 5:肝郁脾虚 / 阴挺(占 10%,情志 + 脾气下陷)

- **核心特征**:阴部坠胀、神疲食少、情志抑郁、脉弦弱
- **代表方**:**补中益气汤 + 山栀、茯苓、青皮**(清肝补脾,兼升中气)/ **归脾汤 + 山栀、丹皮**
- **辨证要点**:「阴中突出如菌子、如鸡冠,四边肿痛者,乃**肝郁脾虚所致**,先以补中益气汤加山栀、茯苓、青皮,清肝补脾、兼升中气」
- **本草溯源**:柴胡(《本经》)升举阳气 + 龙胆草(《本经》)清肝泻火—— 一升一降,斡旋中气

| 内服方 | 外治方 | 病机 | 出处 |

### 9.2 「湿热」与「寒湿」分层(陈实功三等说)

- **湿热下注 → 龙胆泻肝汤**(苔黄腻、口苦尿黄)
- **寒湿凝滞 → 蛇床子散**(苔白腻、阴部冷)
- **虫蚀蕴毒 → 补心汤 + 狼牙汤外洗**(溃烂如虫蚀)
- **气血两虚 → 回阳生肌散 + 黄耆为君**(久溃不敛)
- **肝郁脾虚 → 补中益气 + 龙胆泻肝**(坠胀神疲)

### 9.3 仲景两方的现代活用

- **狼牙汤**:现代用「仙鹤草芽」代狼牙,治外阴溃疡、白塞氏病阴部表现、糖尿病合并外阴感染

## 十三、关键禁忌与注意事项

### 13.1 5 大误治警示

| 错误做法 | 后果 | 正确做法 |
|---|---|---|
| 见阴部红肿即用苦寒清利,不查脉 | 苦寒伤阳,转为寒凝 | 「**少阴脉滑而数**」是湿热;「脉沉迟」是寒湿,反之 |
| 见阴疮即用龙胆泻肝汤,不查溃烂度 | 虫蚀型单用清利,不能解毒杀虫 | 虫蚀型必须配**狼牙汤外洗 + 补心汤托毒** |
| 见久溃即用收涩药,不查气血 | 收涩闭门留寇,溃烂加重 | 气血两虚型必须**黄耆为君 + 回阳生肌散** |
| 见阴部坠胀即用补中益气汤,不查情志 | 单补气不疏肝,肝郁加重 | 肝郁脾虚型必须**朝补中益气 + 晚龙胆泻肝** |
| 狼牙汤不外洗而内服 | 狼牙有毒,内服伤正 | 仲景原方就是**外洗**——绵缠箸如茧,浸汤沥阴中 |

### 13.2 5 大临床警示

1. **仲景原方不出内服**——狼牙汤、蛇床子散皆为外治方,内服易中毒/伤脾胃
2. **阴蚀多发于嫠寡**(邹澍《本经疏证》),需关注情志 + 全身症状
3. **阴疮与阴挺(子宫脱垂)、阴痒、阴肿常合并出现**(《医宗金鉴·妇科心法》),需联合辨证
4. **下疳阴疮(男子交合传染)**与**妇人阴蚀**病机略异——男子多肝经湿热下注,妇人多七情郁火 + 湿热
5. **现代医学对应**:**外阴溃疡 / 白塞氏病阴部表现 / 阴部疱疹 / 糖尿病合并感染**均可按此辨证,但需排除梅毒/艾滋等特异性感染

### 13.3 阴疮与狐惑(白塞氏病)的鉴别

> 仲景《金匮》狐惑病 = 「**蚀于喉为惑,蚀于阴为狐**」——蚀于喉者用甘草泻心汤,蚀于阴者用**狼牙汤**(同阴蚀)。

→ **白塞氏病(口-眼-生殖器三联征)的中医辨证** = 阴蚀(下)+ 喉痹(上),治疗分上治喉、下治阴,与单纯阴疮不同。

## 十四、一句话核心心法

> **「阴疮」= 前阴/后阴的慢性溃疡性疮疡,仲景立「狼牙汤外洗 + 蛇床子散坐药」为外治根基;陈实功《外科正宗》立「湿阴疮/妒精疮/阴蚀疮」三等说为中医外科分类定型;现代中医赵炳南立「回阳生肌散 + 阴蚀黄连膏 + 黄连甘乳膏」为现代外治三大支柱**——治法总原则:**湿热者清利、虫蚀者杀虫、虚寒者温补、久溃者托毒生肌**(「解毒杀虫 / 扶正祛邪 / 内服外治并行」)。

**临床铁律**:
1. **湿热下注是主流**(龙胆泻肝汤证)——但**阴部冷凉 = 寒湿**(蛇床子散证),反向治则致命
2. **虫蚀蕴毒最重**(阴蚀几尽)——必须**外洗狼牙汤 + 内服补心汤**,单用清利不够
3. **气血两虚型「黄耆为君」**——阴疮久溃不敛的托毒生肌关键药
4. **仲景原方是外治方**——狼牙汤不内服、蛇床子散不煎服,皆为局部用药
5. **阴疮多合并阴痒、阴肿、阴挺**——需联合辨证,单治一证易反复
6. **阴蚀多发嫠寡(寡妇)**——情志内伤 + 气血亏虚,需兼顾心理疏导
