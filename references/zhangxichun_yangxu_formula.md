## 一、张锡纯治阳虚的核心心法(原文直引)

### 1.1 水肿辨证总论

**张锡纯论水肿辨证**(引自六味地黄丸证条,BM1:24):

> "水肿之证,当详辨其阴虚、阳虚,或阴阳两虚。
> **阳虚者气分亏损,可单用重用黄芪**;
> 阴虚者,其血分枯耗,宜重用滋阴之药。"

(来源:zysjllsj:8612)

### 1.2 三焦阳虚与水饮

**张锡纯论三焦阳虚**(《医学衷中参西录·加味苓桂术甘汤》条):

> "**人之水饮,非阳气不能宣通**。
> 上焦阳虚者,水饮停于膈上。
> 中焦阳虚者,水饮停于脾胃。
> **下焦阳虚者,水饮停于膀胱。**
> 水饮停蓄既久,遂渐渍于周身,而头面肢体皆肿,甚或腹如抱瓮,而膨胀成矣。"

(来源:zysjllsj:99219,books_json/0513_医学衷中参西录.json L1301)

### 1.3 参附汤固下焦元阳

**张锡纯论参附汤机制**(同上):

> "人参同附子,名**参附汤**(能固下焦元阳将脱),
> 协同桂枝,更能助下焦之阳
> (桂枝上达胸膈,下通膀胱,故肾气丸用桂枝不用肉桂)。"

(来源:zysjllsj:99219)

### 1.4 三焦并治总纲

**张锡纯自述加味苓桂术甘汤方义**:

> "此方用苓桂术甘汤,以**助上焦之阳**。
> 即用甘草协同人参、干姜,以**助中焦之阳**。
> 又人参同附子,名参附汤,协同桂枝,
> **更能助下焦之阳**。
> **三焦阳气宣通,水饮亦随之宣通,而不复停滞为患矣。**"

(来源:books_json/0513_医学衷中参西录.json L1301)

> "至灵仙与人参并用,治气虚小便不利甚效(此由实验而知,故前所载宣阳汤并用之)。

> 若肿胀甚剧,恐其壅滞者,去之亦可。"

> 即化膀胱之凝滞,以达溺管也。
>
> 凉甚者,肉桂、附子、干姜皆可酌加。
> 气分虚者,更宜加人参助气分以行药力。"

## 六、张锡纯辨证肾阳虚的核心指标(原文提炼)

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 脉象   : 沉迟无力(张锡纯原话反复强调)                    │
│ 2. 自觉   : 寒凉                                            │
│ 3. 部位   : 下焦阳虚 → 水饮停膀胱 → 小便不利/水肿         │
│ 4. 兼证   : 畏寒、自汗、气短、面白浮肿                      │
│ 5. 舌象   : 舌淡、苔白滑/腻                                  │
│ 6. 水饮   : 头面肢体皆肿,腹如抱瓮                          │
│ 7. 辨证陷阱: 脉浮水肿(风水)vs 脉沉水肿(阳虚)完全不同     │
│             浮 → 越婢汤发汗;沉迟 → 加味苓桂术甘汤         │
└─────────────────────────────────────────────────────────────┘
```

**张锡纯·脉浮脉沉辨证关键**(books_json/0513 L1301):

> "脉沉水肿,与脉浮水肿迥异。
> 脉浮者,多系风水,腠理闭塞,小便不利。
> 当以《金匮》越婢汤发之,通身得汗,小便自利。
> 若浮而兼数者,当是阴虚火动,宜兼用凉润滋阴之药。
>
> 脉沉水肿,亦未可遽以凉断。
> 若沉而按之有力者,系下焦蕴热未化,仍当用凉润之药,
> 滋阴以化其阳,小便自利。
> 惟其脉沉而且迟,微弱欲无,询之更自觉寒凉者,
> 方可放胆用此汤(加味苓桂术甘汤)无碍。"

## 七、张锡纯的「三焦并治」思维 — 不是单纯补肾阳

张锡纯治肾阳虚,**不是简单「补肾阳」**,而是「三焦阳气并温」:

```
       上焦阳虚                中焦阳虚               下焦阳虚(肾)
       ───────                ────────               ────────
       苓桂术甘汤              人参 + 干姜           参附汤 + 桂枝
       (水饮停膈上)            (水饮停脾胃)           (水饮停膀胱)
                                                  = 三焦并温
                                                  = 加味苓桂术甘汤

「三焦阳气宣通,水饮亦随之宣通,而不复停滞为患矣」
              ───── 张锡纯原话
```

## 九、张锡纯治阳虚的「禁忌与边界」

**1. 甘草的取舍**(books_json/0513 L1301):

> "肿满之证,忌用甘草,以其性近壅滞也。
> 惟与茯苓同用,转能泻湿满,故方中未将甘草减去。
> 若肿胀甚剧,恐其壅滞者,**去之亦可**。"

**2. 桂枝与肉桂的区别**:

> 「(桂枝)上达胸膈,下通膀胱,故肾气丸用桂枝不用肉桂」
> — 桂枝走表通阳,肉桂温肾命门,治下焦寒凝时肉桂更直接

**3. 脉象与治法的分界**:

- 脉沉 + 按之有力 → 下焦蕴热 → **凉润药**(不可遽凉断,但凉润为主)
- 脉沉 + 微弱欲无 + 自觉寒凉 → **放胆用加味苓桂术甘汤**

**4. 真火衰微的标志**:

> 「若药服数剂后,脉仍如故,病虽见愈,实无大效,
> 此**真火衰微太甚,恐非草木之品所能成功**。
> 故又用生硫黄少许,以补助相火。」
> — **必加生硫黄**,这是张锡纯治肾阳虚的「最后王牌」

## 十、与其他专题的关联

| 关联方向 | 备注 |
|---|---|
| **真武汤**(伤寒论) | 同样治脾肾阳虚水停,但真武汤走「温阳利水」,加味苓桂术甘汤走「三焦并温」,思路相通但张锡纯扩展更广 |
| **肾气丸**(金匮) | 张锡纯点名:肾气丸「用桂枝不用肉桂」治肾阳虚,真武汤也是经典 |
| **苓桂术甘汤**(伤寒论) | 加味苓桂术甘汤 = 苓桂术甘汤 + 参姜附仙(张锡纯扩展版) |
| **参附汤**(世医得效) | 张锡纯多次引用「人参同附子名参附汤,固下焦元阳将脱」 |
| **生硫黄用法** | 张锡纯独创,温通汤等方中无,只在加味苓桂术甘汤方后注出现,「真火衰微」时用 |
| **温病忌用辛温** | 张锡纯论脉浮水肿用越婢汤(辛凉发汗),与本专题的「阳虚辛温利水」形成「温病 vs 阳虚」的辨证对照 |
