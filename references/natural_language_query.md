# 自然语言查询的 4 种意图模式

`scripts/verify_prescription.py` 支持 4 种自然语言查询模式。所有模式都用**规则 + 关键词**匹配（**不调 LLM**），保证本地可重现 + 快速响应。

## 意图 1：病证模式

**触发关键词**：`治疗 / 治 / 主治 / 主` + 病证 + `的核心药 / 高频药 / 常用药 / 方剂 / 中药 / 药物`
**触发样例**：
- "治疗皮肤瘙痒的核心药"
- "中风的高频药"
- "痹证的核心药"
- "目系疾病有哪些常用药"

**执行**：
1. 解析出 `disease`（病证名）
2. 在 `DISEASE_KEYWORD_MAP` 查找同义词（痒/瘾疹/瘙痒/风瘙痒 → 皮肤瘙痒）
3. 跑 4 步流程：同病证多方归纳 → 高频核心药 → 本草原文 → 总结

---

## 意图 2：药模式

**触发关键词**：`X 的本草 / X 的药性 / X 的功效 / X 的本草功效 / X 的原始功效 / X 的本草记载`
**触发样例**：
- "麻黄的本草功效"
- "附子的药性"
- "桂枝的功效"
- "细辛的本草"

**执行**：
1. 解析出 `herb`（药名）
2. 从 zysjllsj 表查 BiaoTi = herb 的章节
3. 优先取 zysjllsj:72xxx 系列（本草原始文献汇编），次取 1xxx 系列（现代中药学）
4. 正则提取本草引文：`《X》云∶主Y...` / `此方主之Y...` / `治Y...`

---

## 意图 3：why 句式

**触发关键词**：`为什么 + X + 用 / 选 / 要 + Y`
**触发样例**：
- "为什么续命汤用麻黄"
- "为什么小青龙汤用细辛"
- "为什么四逆汤用附子"

**执行**：
1. 解析出 `herb` = Y（被使用的药）
2. 跳到 Y 的本草章节（同意图 2）
3. **回答 Y 在本草中的原始主治**（如麻黄"破癥坚积聚"）—— 这是 Y 被选用的潜在依据

---

## 意图 4：方剂反查（公式表专用）

**触发关键词**：`含 / 有 / 用 + X + 方 / 方剂 / 药方`
**触发样例**：
- "含细辛的方剂"
- "有麻黄的方"
- "用附子的药方"

**执行**：
1. 解析出 `herb` = X
2. 在 zysjllsj 表查 NeiRong LIKE '%X%' AND BiaoTi 含方剂后缀
3. 按优先级排序：
   - **priority -1**：经典方（PURE_NAME_MAP 命中，理中汤/真武汤/苓桂术甘汤等）
   - **priority 0**：含《伤寒论》/《金匮》/《千金》/《局方》等重要书名
   - **priority 1**：含《集验》/《经效》/《必效》等次要书名
   - **priority 2**：数字编号/带括号标记方（1.XXX、一、XXX、〔附〕XXX）
   - **priority 3**：其它纯名方
4. 启发式字典识别出处/作者/朝代（PURE_NAME_MAP + TITLE_HEURISTIC）

---

## 意图 5：主治反查（公式表专用）

**触发关键词**：`破X积聚 / X积聚 / X癥瘕 + 方剂`
**触发样例**：
- "破癥坚积聚的方剂"
- "症瘕积聚"

**执行**：
1. 解析出"主治"短语
2. 第一步：查 zysjyj 表 Chufang 字段（方剂 Chufang 通常不含本草原文）
3. 第二步：查 zysjllsj 表 BiaoTi 是药名（≤4 字）的章节 + NeiRong 含该短语
4. 输出本草主治含该短语的药物 + zysjllsj 章节号 + 上下文

---

## 解析顺序

```python
# parse_query() 的实现顺序
1. "为什么 + X + 用 Y" → herb_bencao (查 Y)
2. "X 的本草/药性/本草功效" → herb_bencao (查 X)
3. "含 X 的方剂" → formula_reverse (查 X)
4. "破 X 积聚 的方剂" → indications (反查本草)
5. 默认: 病证模式 (查 disease)
```

**优先级**：更具体的意图（如"含 X"）优先于通用模式（如"X 的核心药"）。

---

## 解析失败的降级

如果自然语言没匹配上任何意图：
- 默认按"病证模式"处理
- 关键词会传给 zysjyj 表的 LIKE 查询（"皮肤瘙痒" → 找含"皮肤"或"瘙痒"的方剂）
- 如果零命中，输出"未找到"

**不要靠 LLM 兜底** —— 会导致不可重现、慢、不一致。
