## 一、消瘰丸的病机演化（4 个时代）

### 1.1 隋·《诸病源候论》巢元方（610 年）—— 外感风热立论

> "小儿身生热疮, 必生瘰疬。其状如结核, 在皮肉间三两个相连累也。**是风热搏于气血, 焮结所生也**。"

> 详见瘰疬条: 风邪毒气客于肌肤而成, 症见初起如梅李枣核, 随处可生, 常互结粘连, 且伴见全身寒热等症, 久则化脓成漏。

**【原文】** 病机 = 外感风热 + 气血壅结（最早期的理论框架）

### 1.2 清·程国彭《医学心悟》1732 —— 肝肾阴虚立论

> "清热滋阴, 化痰散结。治**肝肾阴号所致的瘰疠**。"

**【原文】** 病机 = 肝肾阴号（本虚）+ 痰火郁结（标实）—— 创方基础

### 1.3 清·四圣心源派（黄元御）—— 足少阳气机立论

**zysjllsj TypeID=1296 【原文】**：

> "瘰疬者, **足少阳之病也**。足少阳以甲木而化气于相火, 其经自头走足, 行身之旁, 目之外眦, 上循耳后, 从颈侧而入缺盆, 下胸腋而行胁肋, 降于肾藏, 以温癸水。相火降蛰, 故癸水不至下寒, 而甲木不至上热。"
>
> "而甲木之降, 由于辛金之敛, 辛金之敛, **缘于戊土之右转也**。**戊土不降, 少阳逆行, 经气壅遏, 相火上炎, 瘀热抟结, 则瘰疬生焉**。"
>
> "肝胆主筋, 筋脉卷屈而壅肿, 故磊落历碌, 顽硬而坚实也。"

**病机 = 戊土不降 → 少阳逆行 → 相火上炎 → 瘀热抟结**

### 1.4 民国·张锡纯《医学衷中参西录》1911 —— 肝胆实火 + 痰瘀互结立论

> "瘰疬之证, 多在少年妇女, 日久不愈, 可令信水不调, 甚或有因之成劳瘵者。其证系**肝胆之火上升, 与痰涎凝结而成**。初起多在少阳部位, 或项侧, 或缺盆, 久则渐入阳明部位。**一颗垒然高起者为瘰, 数颗历历不断者为疬**。身体强壮者甚易调治。"

> "此方重用牡蛎、海带, 以消痰软坚, 为治瘰疬之主药, 恐脾胃弱者, 久服有碍, 故用黄耆、三棱、莪术……"

**【原文】** 病机 = **肝胆实火 + 痰瘀互结** + 兼顾脾胃

## 二、消瘰丸 4 医家组方对比（核心）

### 2.1 ① 程国彭消瘰丸原方（1732 · 清乾隆）【原文】

**出处**: 《医学心悟》卷四

```
元参（蒸）4 两 + 牡蛎（煅, 醋淬）4 两 + 贝母（去心, 蒸）4 两
共为末, 蜜丸, 每服三钱 (9 克), 开水下, 日二服
```

**【原文 card_id: 8e73ff8ba159676b】**

**别名**: 消疠丸（《疡医大全》卷十八 顾世澄）

**治法**: 清热滋阴, 化痰散结

**适用人群**:
- 瘰疬初起（少阳部位, 项侧/缺盆单个）
- 肝肾阴号 + 痰火郁结
- 舌红少苔 + 脉细数

**临床要点**:
- 已溃者用九制首乌研末蜜丸【原文 zysjllsj:290】
- 外用羊屎、杏仁各五钱, 烧研细末, 猪骨髓调搽【同上】

### 2.2 ② 清代 14 味变方（清 · zysjllsj TypeID=761）【原文】

```
夏枯草 8 两 + 玄参 5 两 + 青盐 5 两
+ 海藻 / 海粉 / 贝母 / 花粉 / 白蔹 / 连翘（去心）
+ 桔梗 / 当归 / 生地 / 枳壳 / 熟大黄
+ 薄荷叶 / 消石 / 生草 各 1 两
酒糊丸, 桐子大, 临卧服
```

**【原文 card_id: 846969e8f2a349e4】**

**治法**: 清肝散结 + 咸寒软坚 + 化痰活血（多管齐下）

**适用人群**:
- 痰凝气滞所致瘰疬痰核, 颈项瘿瘤
- 皮色不变, 或肿或痛
- 痰凝为主 + 经多阴复合证

**与原方对比**: 加 **夏枯草**（清肝散结主药）+ **海藻/海粉/消石**（咸寒软坚）+ **青盐**（引经入肾）+ **当归/生地**（养血滋阴）

### 2.3 ③ 张锡纯化裁方（1911 · 民国）【原文】

**出处**: 《医学衷中参西录》上册

```
煅牡蛎 300 克（君, 软坚）
+ 生黄耆 120 克（臣, 补气护胃）
+ 三棱 60 克 + 莪术 60 克（化瘀散结, 张氏特色）
+ 朱血竭 30 克 + 生明乳香 30 克 + 生明没药 30 克（活血止痛）
+ 龙胆草 60 克（清肝胆实火）
+ 玄参 90 克（滋阴）
+ 浙贝母 60 克（化痰）
共为细末, 蜜丸桐子大, 每服三钱 (9 克)
```

**【原文 card_id: 68e4a1f3153165cf + zysjllsj:513】**

**送服法**: **用海带五钱（15 克）, 洗净切丝, 煎汤送下, 日再服**【原文】

**核心创新**:
1. **首次将「活血化瘀」引入瘰疬治疗** —— 三棱/莪术/血竭/乳香/没药（伤科圣药移植）
2. **首次加入补气护胃** —— 黄耆（防软坚药伤脾胃）
3. **加重清肝胆实火** —— 龙胆草（而非程氏原方的滋阴）
4. **配海带送服** —— 海带咸寒软坚, 增消痰散结之力

**适用人群**:
- 少年妇女, 瘰疬日久
- 月经不调（"信水不调"）
- 体虚有瘀 + 肝胆火 + 痰凝

## 五、临床决策算法

```
第 1 问: 瘰疬已溃还是未溃？
├─ 已溃 → 程氏原方 + 九制首乌蜜丸 + 外敷（羊屎/杏仁/猪骨髓）
└─ 未溃 → 第 2 问

第 2 问: 年龄 / 性别？
├─ 少年妇女 + 月经不调 → 张锡纯化裁方（送海带汤）
├─ 老年 / 中年 → 第 3 问
└─ 儿童 / 体弱 → 程氏原方（精简无负担）

第 3 问: 病程长短？
├─ 初起单个 → 程氏原方
├─ 数颗历历不断（痰凝为主）→ 14 味清变方
└─ 久病体虚有瘀 → 张锡纯化裁方

第 4 问: 兼证？
├─ 兼潮热盗汗 → 周次青汤剂
├─ 兼脾胃虚弱 → 张锡纯化裁方（已有黄耆护胃）
└─ 兼情志不舒 → 张锡纯化裁方（已有龙胆草清肝）
```

## 七、4 医家创新点对比

### 7.1 程国彭《医学心悟》1732

**创新**: **首立消瘰丸** —— 3 味精简构架, "**玄参滋阴 + 牡蛎软坚 + 贝母化痰**"。**奠定了"滋阴软坚化痰"基本治法**, 后世所有变方都未脱离这 3 味。

### 7.2 清代 14 味方

**创新**: **从「阴虚」扩展到「痰凝气滞」** —— 加夏枯草（清肝散结）+ 海藻/海粉/消石（咸寒软坚）+ 青盐（引经入肾）。

### 7.3 张锡纯《医学衷中参西录》1911

**创新**: **首次将「活血化瘀」引入瘰疬治疗** —— 三棱/莪术/血竭/乳香/没药（伤科圣药移植）。**首次加入补气护胃**（黄耆）。

**核心病机升级**: 痰火 → **痰瘀互结 + 气虚**。

### 7.4 周次青现代方

**创新**: **从丸剂改汤剂** —— 更适合现代煎服; 加**三黄泻火**（阴虚火旺专属）+ **酸枣仁/浮小麦**（兼汗证/情志不遂）。

**核心病机升级**: 痰瘀 → **阴虚火旺 + 情志不遂 + 腠理不固**。
