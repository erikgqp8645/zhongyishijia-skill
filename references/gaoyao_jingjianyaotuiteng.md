# 颈肩腰腿痛膏药方大全

> **核心心法**：膏药（薄贴）是中医外治法的核心载体，对**颈肩腰腿痛、筋骨痹痛、跌打损伤**三大类病证有独特优势——清代吴尚先《理瀹骈文》「薄贴论」明确指出「**其病既有定所，在于皮肤筋骨之间，可按而得者，用膏贴之，闭塞其气，使药性从毛孔而入其腠理，通经贯络，或提而出之，或攻而散之，较之服药尤有力，此至妙之法也**」。
>

## 三、朝代溯源（7 个朝代）

### 1. 汉（公元 25-220 年）—— 膏药雏形
- **武威汉代医简《治百病方》**：有 12 枚木简和 86 号木牍涉及皮肤病，有治疗痈、痤、溃疡、瘙痒、大风（麻风）等，从「**治百病膏药方**」「**治千金膏药方**」简及 86 号木牍「**大风方**」中可以看出，不仅载有病名，还记述若干病状体征，所用药物的剂量、制备和使用方法；甚至还提到经治后的转归。其治法较《五十二病方》有所进步，如以药膏外敷治疗疮痈就相当高明：**多层涂药，中央留孔，既促进炎症局限**。

### 2. 唐（公元 618-907 年）—— 薄贴之名确立
- **唐·孙思邈《千金要方》**「薄贴」之名正式确立
  - **蠲痛五汁膏**（寒湿腰背痛）、**丹参膏**（贼风肢节麻痛）、**白芷膏**（风毒流注筋脉挛急）、**防己膏**（产后中风筋脉挛急）、**汉防己膏**（脚气风毒肿满疼痛）、**赤膏**（久温痹骨节疼痛）、**苍梧道士陈元膏**（四肢痹躄）、**桂枝石膏汤**（伤寒颈项强肿）
  - **膏药之发明已久**——唐人已有薄贴之名，知膏药之发明已久（《中国医学大辞典》）
- **唐·王焘《外台秘要》**「诸伤折淋熨贴并膏药」专题——收录大量伤折膏药

### 3. 宋（公元 960-1279 年）—— 膏药大发展
- **宋·王怀隐《太平圣惠方》**

  - 「**第二十九门（膏药）**」专题，涵盖一切风毒流注筋骨疼痛
  - **蓖麻膏**、**穿山甲膏**、**桂芸膏**、**接骨桂芸膏**等跌打筋骨方

  - **钩藤膏**（肝血少生风、皮肤干揭、筋脉挛缩）

- **明·楼英《医学纲目》（1565 年）**
  - 「**膏药类**」专题——收录各代名方

### 5. 清（公元 1644-1912 年）—— 膏药集大成
- **清·吴尚先《理瀹骈文》（1864 年）**——清代膏药专著，**膏药外治法集大成之作**
  - **「薄贴论」**（ID=20378）：「今所用之膏药，古人谓之薄贴。其用大端有二∶一以治表，一以治里。治表者，如呼脓去腐，止痛生肌，并摭风护肉之类。其膏宜轻薄而日换，此理人所易知；治里者，或驱风寒，或和气血，或消痰痞，或壮筋骨，其方甚多，药亦随病加减。其膏宜重浓而久贴，此理人所难知，何也？盖人之疾病，由外以入内，其流行于经络脏腑者，必服药乃能驱之。若其病既有定所，在于皮肤筋骨之间，可按而得者，用膏贴之，**闭塞其气，使药性从毛孔而入其腠理，通经贯络，或提而出之，或攻而散之，较之服药尤有力，此至妙之法也**」
  - 「**第二节·薄贴各方**」（ID=152755）：唐人已有薄贴之名，知膏药之发明已久。疡证半多湿热，不宜于温，阴寒凝结之证，则清凉正在所忌。**而杂病之经络筋骨肢节间证，亦有宜于外治者，此温煦一法，正不可少**
  - 「**附∶杨州存济堂药局膏药方**」——清代膏药店临床实践
  - 收录方剂：**蠲痛五汁膏**、**集宝疗痹膏**、**除湿固本膏**、**贴腰膏**、**阳和解凝膏**等
- **清·吴谦《医宗金鉴》（1742 年）**
  - **金不换膏**（跌打筋骨酸痛）、**宝珍膏**（风寒麻木筋骨疼痛）、**坚骨壮筋膏**（伤筋骨折）、**虎骨膏**（腰腿疼痛筋脉拘挛）、**代灸膏**（风湿痹腰痛）、**加味太一膏**（跌扑伤损+筋骨走注作痛）

- **清·张璐《张氏医通》（1695 年）**
  - **鹿茸膏**（五劳七伤腰痛）、**登仙膏**（腰痛+半身不遂）
- **清·程鹏程《急救广生集》（1805 年）**
  - **筋骨闪挫膏药方**（71 味大复方）、**风湿诸般疼痛膏药**（玄参/苦参/黄柏方）

## 六、5 大临床实战首推方（按安全度分级）

### 安全级（日常保健 / 家用）

**1. 蠲痛五汁膏**（清·吴尚先《理瀹骈文》）
- **处方**：凤仙梗（捣汁）、老姜汁、蒜汁、韭汁、葱汁各等分
- **功效**：寒湿气袭经络血脉痛，痛于两臂两股、腰背环跳之间
- **优势**：五汁合用，全为食材，安全无毒；适合家庭熬制
- **现代用**：风湿性肌纤维织炎、慢性腰肌劳损

**2. 贴腰膏**（清·吴尚先《理瀹骈文》）
- **处方**：生姜一斤捣汁四两，水胶一两，同煎成膏
- **用法**：浓纸摊贴腰眼甚效
- **优势**：仅 2 味药，制作简单，老百姓可用
- **现代用**：风寒腰痛、寒湿腰痛

### 救急级（急性扭挫伤 / 疼痛明显）

**3. 集宝疗痹膏**（清·吴尚先《理瀹骈文》）
- **处方**：川乌4钱、草乌4钱、南星4钱、半夏4钱、当归4钱、红花4钱、独活4钱、羌活4钱、大黄4钱、桃仁4钱、山甲1钱、肉桂1钱、白芷5钱、陀僧2两、硫黄半斤、松香1斤、生姜汁1钱、麻油1斤、竹汁1碗
- **功效**：风寒湿痹
- **优势**：经典风寒湿痹外治膏，吴尚先亲定；注意川乌/草乌/南星/半夏有毒

**4. 阳和解凝膏**（清·王洪绪《外科证治全生集》）

- **功效**：温经和阳、行气活血、驱风散寒、化痰通络
- **现代用**：淋巴腺结核、骨与关节结核初期、寒湿痹痛

## 八、临床决策算法

```
患者主诉：颈肩腰腿痛
    ↓
【STEP 1】辨急性/慢性
    ├─ 急性扭挫伤 → 跌打损伤膏（红药贴膏/狗皮膏/活血止痛膏/接骨膏）
    └─ 慢性疼痛 → 进入 STEP 2

【STEP 2】辨虚实
    ├─ 虚证（肾虚/气血虚） → 鹿茸膏/鹿胎膏/虎骨膏/登仙膏/补天膏
    └─ 实证（寒湿/瘀血） → 进入 STEP 3

【STEP 3】辨部位
    ├─ 颈项痛 → 桂枝石膏汤 + 颈项按摩
    ├─ 肩臂痛 → 蠲痛五汁膏外敷肩井/臂臑
    ├─ 腰痛 → 贴腰膏（寒湿）/摩腰膏（老人虚）/代灸膏（风湿）
    ├─ 腿膝足痛 → 退痛膏（足痛）/汉防己膏（脚气）
    └─ 全身筋骨痹痛 → 集宝疗痹膏/阳和解凝膏/除湿固本膏

【STEP 4】辨寒热
    ├─ 寒证 → 阳和解凝膏/集宝疗痹膏/代温灸膏/回阳玉龙膏
    └─ 热证 → 跌打膏/活血止痛膏/伤湿止痛膏

【STEP 5】安全性检查
    ├─ 含川乌/草乌/南星/半夏 → 医师指导
    ├─ 含朱砂/雄黄/铅丹 → 短期使用
    └─ 纯食材/纯植物 → 家用安全（蠲痛五汁膏/贴腰膏）
```
