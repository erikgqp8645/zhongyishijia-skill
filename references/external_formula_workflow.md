# 外治法方剂检索工作流(病机 × 给药途径)

> **适用提问**：「有没有针对 X 的**外敷**方?」「痰瘀互结的**外用**膏剂有哪些?」
> 「贴脐/箍围/熨法一类的方子?」「有没有熨法治疗中焦痞满的方?」
> **一句话心法**:外用方的病机写在**组成/制法/用法/按语**里,不写在主治里 —— 病机列与主治列
> **分列扫描、组内 OR、组间 AND**,只扫主治列会漏掉整类方。

---

## 一、为什么需要单独一份工作流

`references/composite_syndrome_query.md` 解决的是**临床理论层**(zysjllsj)的复合主题检索;
`references/gaoyao_query_workflow.md` 解决的是**单一外用主题**(颈肩腰腿痛膏药)的方剂专题构建。

本工作流解决的是**第三种形状**:方剂表(zysjyj)里按**给药途径**这一维度检索 ——
「外敷/外贴/摊贴/熨/洗/涂/填塞」这一类方剂,病机不限、部位不限。

它与 gaoyao 工作流的关键区别:gaoyao 是**一个主题做透**(主题词 + 部位白名单 + 黑名单去噪),
本工作流是**一个剂型维度横切**(任意病机 × 外治途径),用于回答「这类病的外治方有哪些」。

---

## 二、方剂表检索的两类列(核心)

外用方的「主治」写的是**成品形态**而不是病机 —— 「治症瘕痞块」「治痰核瘰疬，未穿破者」;
病机(痰、瘀)在**组成/制法/用法/按语**里。两类关键词必须各扫各的列组:

| 关键词类型 | 扫哪些列 | 典型词 | 命中什么 |
|---|---|---|---|
| **病机词** | `ChuFang` `ZhiFa` `HuaXueCF` `YongFaYL` `ZhuYi` `LinChuangYY` `BeiZhu` | 痰 / 瘀 / 痰瘀 | 白芥子、莪术、三棱、阿魏、麝香(药味即病机) |
| **部位/病名词** | `GongNengZZ` `XingZhuang` `ChuFang` | 痞 / 积聚 / 症瘕 / 痰核 / 瘰疬 | 「症瘕痞块」「痰核瘰疬」等成品适应症 |
| **给药途径词** | `HuaXueCF` `YongFaYL` `GuiGe` → 退 `ZhiFa` `XingZhuang` `ZhuYi` `FuFang` | 敷/贴/摊/箍围/熨/洗/熏/涂/搽/填塞 | 贴脐上 / 以热手磨擦 / 摊贴 / 熨之 |

**筛选逻辑**:病机组内 OR、部位组内 OR、**两组之间 AND**。

**为什么组间是 AND**:「痰瘀」和「痞块」在同一方里是**同时成立**才构成「痰瘀所致痞块」这个命题;
任一单独命中都不足以定位到「痰瘀互结的外敷方」。

## 三、给药途径分类(库内实作)

| 途径 | 库内用词 | 备注 |
|---|---|---|
| **贴敷** | 敷贴/外敷/外贴/箍围/摊贴/贴于/贴患处/贴脐/敷脐/掺/摊 | 占比最大 |
| **熨法** | 熨/揉熨/热手摩/摩之/摩擦(**库内作「磨擦」**)/熨之 | 中焦痞满的特色外治法 |
| **洗浴** | 淋洗/外洗/浸洗/洗之/熏洗/熏 | 多见于疮疡、阴痒 |
| **涂布** | 外涂/涂敷/外搽/搽之/涂之 | 多见于皮肤病 |
| **填塞坐药** | 填塞/坐药/纳之 | 少��� |

**「贴脐」是中焦外敷的特定途径** —— 官方成药方(如阿魏化痞膏、二龙膏)明写「贴脐上」,
与「贴患处」是不同的给药设计,报告时要分开标。

## 四、坑 14:同名方多版本必须并陈

`zysjyj` 按「书 × 卷 × 条」录入,同名方在不同书里各自成条,主治方向可能不同。
**不能当重复条目去重** —— 保留全部版本 + 各带 ID/出处/主治,版本数 > 1 时显式标注。

已确认多版本者(库内实测):`加减紫金丹`(2,主治病机方向不同) / `消核膏`(2) / `化核膏`(2) /
`化痞膏`(3+) / `冲和膏`(3) / `阳和解凝膏`(2) / `金丝万应膏`(6) / `大黄膏`(8+) / `琥珀膏`(10+)。
详见 `references/known_pitfalls.md` 坑 14。

## 五、坑 5:方名在方剂表查不到 ≠ 库里没有

古方名可能**只存在于 zysjllsj 正文**而未立条目。
例:「新加栝蒌薤白汤」在 zysjyj 查 `栝蒌薤白` / `瓜蒌薤白` 均 **0 条**,
但它完整存在于俞根《重订通俗伤寒论·夹痞伤寒》正文里(含完整组成与「因于痰瘀成囊者」主治语)。

**规则**:方名 0 命中时,必须回 zysjllsj 全文搜该方名,再决定「库里没有」。

## 六、输出形状(Erik 偏好)

Erik 要「精确数据决策」,不接受模糊结论。外治法方剂检索的标准输出:

1. **命中口径表** —— 扫描基数 / 命中方名组数 / 命中版本数,标明是行级还是收敛
2. **按给药途径分组** —— 贴敷 / 熨法 / 洗浴 / 涂布 分组,每组一张表
3. **每首方给全字段** —— 方名 / 出处 / 原文主治 / **组成** / **制法** / **用法** /
   途径证据位(哪一列判定的外治)
4. **同名多版本** —— 显式标注版本数并各列一行
5. **鉴别要点** —— 同名方不同版本的主治方向差异(临床会选错)
6. **检索局限** —— 库内写法的取舍(如「磨擦」vs「摩擦」)

**原文引用铁律**:引用不带省略号(见 `references/zhongyi_source_citation_principle.md`)。

**Erik 明确要过配伍** —— 「补齐配伍」时给**全字段**(组成+制法+用法+出处+原文主治),
不能只给主治摘要;跨表方(如上文「新加栝蒌薤白汤」)要标明它取自 zysjllsj 正文而非 zysjyj 表。

## 七、一键跑

```bash
# 病机 × 外治法
python3 scripts/external_formula_query.py --pathology 痰 瘀

# 加部位限定
python3 scripts/external_formula_query.py --pathology 痰 瘀 --indication 痞 积聚

# 限定给药途径
python3 scripts/external_formula_query.py --pathology 痰 瘀 --route 熨

# 按药味反查外用方
python3 scripts/external_formula_query.py --pathology 白芥子 --route 贴敷 --top 5

# JSON 输出
python3 scripts/external_formula_query.py --pathology 痰 瘀 --json
```
