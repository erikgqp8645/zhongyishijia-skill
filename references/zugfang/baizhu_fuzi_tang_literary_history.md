## 1. 一句话核心

**白术附子汤 = 术附汤家族第 5 号变法方**,位于「桂枝附子汤(表阳重) → 白术附子汤(表阳中) → 甘草附子汤(表阳轻)」的**中段**,对应**风湿相搏骨节烦疼**的主证。临床选用时,看患者「疼痛严重程度 + 大便坚/利 + 有无水肿」决定走桂枝/白术/甘草哪个方,或下移真武汤治水泛。

## 2. 原方与同源族谱

### 2.1 祖方·术附汤 (术附汤本祖方)

```
术附汤(术附汤·本祖方)
  - 治证:治寒湿体痛。
  - 组成(原方):术、附
  - 出处:张璐《张氏医通》(自拟祖方,无《伤寒》/《金匮》原方)
  - 同方异名:近效术附汤、玉函术附汤
```

### 2.2 9 个变法方家族全表(术附汤·同源 9 方)

| # | 方名 | 加减 | 主治证 |
|---|---|---|---|
| 1 | 参附汤 | (治证即变法) | 脾肾阳虚,厥逆自汗 |
| 2 | 术附汤 | (本祖方) | 寒湿体痛 |
| 3 | 附汤 | 术附汤去术加黄 一两(蜜酒炒) | 元阳衰弱,虚风自汗 |
| 4 | **桂枝附子汤** | **术附汤去术** | 风湿身重烦疼,不能转侧 |
| **5** | **白术附子汤** | **术附汤本方用术一两二钱。附六钱。加甘草六钱。生姜一两。大枣十二枚** | **风湿相搏,骨节烦疼** |
| 6 | **甘草附子汤** | **术附汤本方用术、附各六钱。加桂枝一两二钱。甘草六钱** | **风湿大便坚,小便自利** |
| 7 | 附子汤 | 术附汤加茯苓、白芍各一两 | 少阴病,背恶寒,脉沉身痛 |
| 8 | 真武汤 | 术附汤本方白术六钱、附子一枚,加茯苓、芍药、生姜各一两 | 少阴下利腹痛,或咳呕,小便不利 |
| 9 | 附子散 | 术附汤本方二味各用一两,加桂心、川芎、独活各半两 | 阴痉 |

> 祖方包含 9 个变法方:张璐自拟 5 个(参附/术附/附汤/附子散) + 引自玉函 3 个(桂枝附子/白术附子/甘草附子/附子汤) + 引自玉函/千金 1 个(真武汤)

## 3. 风湿三方阶梯(仲景原方体系)

张仲景在《伤寒论》/《金匮要略》中对「风湿阳虚」的**阶梯化辨证论治**模型:

```
┌────────────────────────────────────────────────────────────────────┐
│  风湿三方阶梯(仲景原方)                                            │
│                                                                    │
│  桂枝附子汤  →  风湿表阳虚重证                                      │
│                 症状:身重烦疼,不能转侧,汗出恶风不欲去衣             │
│                 术附汤去术(纯附子+桂枝解表,无白术之壅)               │
│                 ↓                                                   │
│  白术附子汤  →  风湿表阳虚中证                                      │
│                 症状:骨节烦疼,掣痛不得屈伸,小便不利,身微肿          │
│                 术附汤本方用术一两二钱、附六钱 + 甘草姜枣              │
│                 ↓                                                   │
│  甘草附子汤  →  风湿表阳虚轻证                                      │
│                 症状:大便坚,小便自利(湿已入里)                       │
│                 术附汤本方用术附各六钱 + 桂枝一两二钱 + 甘草          │
│                                                                    │
│  → 临床选用原则:                                                  │
│    不能转侧(重) → 桂枝附子汤                                       │
│    骨节烦疼(中) → 白术附子汤                                       │
│    大便坚小便利(轻) → 甘草附子汤                                  │
└────────────────────────────────────────────────────────────────────┘
```

### 3.1 张璐按语(玉函三方对比)

张璐《张氏医通》卷十六·术附汤附方按语:

> **「桂枝附子、白术附子、甘草附子三方,皆本术附汤方而立。**
> **一加桂枝、甘草、姜、枣,以治身重烦疼不能转侧。其病全在躯壳,无关于里。故于本方除去白术,使桂、附专行躯壳,而振驱风遂湿之功。用甘草以缓桂、附之性,不使其汗大泄。汗大泄则风去而湿不去也。风在疾祛,湿在缓攻,故用生姜之辛以散之,大枣之甘以缓之,则营卫之开阖有权,风湿无复入之虞矣。**
> **一加甘草、姜、枣,以治骨节烦疼掣痛等证。浑是湿流关节之患,故于本方但加甘草以缓术、附之性,姜、枣以司开阖之机。风之见证本轻,故无藉于桂枝也。**
> **一加桂枝、甘草,以治风湿大便坚、小便自利。以病气内犯,故于本方加桂枝助附子以杜内贼之风湿。加甘草助白术以和二便之偏渗。故大便虽坚,法无下夺之理。」**

按语核心:**3 方都基于术附汤本方,差异在「桂枝」「甘草」「姜枣」的加与减 → 决定驱风 / 缓湿 / 内攻的不同侧重**。

### 3.2 真武汤(水湿重证·阳虚水泛)

如果风湿失治、湿从寒化 → **水湿内停** → 真武汤:

```
真武汤 = 术附汤本方白术六钱、附子一枚 + 茯苓、芍药、生姜各一两
  治证:少阴下利腹痛,或咳呕,小便不利
  仲景语:「少阴病二三日不已,至四五日腹痛自利,四肢沉重,或咳或呕,其人内外皆是水气。」
  张璐注:「故用生姜佐茯苓、术、附以利水为务。水去则真阳自复。」
  → 与附子汤对比:仅差「人参」一味!
    附子汤 = 术附汤 + 人参 + 茯苓 + 芍药(无生姜,治阳虚身痛)
    真武汤 = 术附汤 + 茯苓 + 芍药 + 生姜(无人参,治阳虚水泛)
```

### 4.2 关键节点

**1. 东汉·张仲景原方确立(约 200 年)**
- 《伤寒论》/《金匮要略》记载桂枝附子汤/白术附子汤/甘草附子汤/附子汤/真武汤
- 3 个「附子方」= 风湿阶梯化辨证
- 「真武汤」 = 阳虚水泛的延伸

**2. 明·王肯堂《证治准绳·类方》收录(约 1600 年)**
- 在「伤劳倦」章中收录白术附子汤(加陈皮/苍术/川朴)
- 扩展了原方治疗范围,从「风湿」到「劳倦内伤」

**3. 清初·张璐《张氏医通》卷十六·术附汤家族定位(1695 年)**
- 张璐第一次把 5 个仲景方 + 4 个自拟方 归并为「术附汤」家族
- 给出风湿三方按语(详细解释 3 方的差异)
- 这是「方祖-变法方」结构化梳理的标志性事件

**4. 清·吴谦《医宗金鉴》(1742 年)**
- 在仲景方注解中,延续张璐的「术附汤家族」思路
- 加了更多临床发挥(具体病案)

**5. 现代·临床活用(2020 年代)**
- 中国中医药报多篇文章:用白术附子汤治疗类风湿关节炎、风湿性关节炎、慢性疼痛
- 验证了「白术附子汤治风湿相搏骨节烦疼」的现代临床价值

## 5. 同病异治对比(「风湿」病证)

| 祖方 | 方 | 治证差异 | 关键加减 |
|---|---|---|---|
| **术附汤** | 桂枝附子汤 | 风湿身重烦疼,不能转侧(表阳重) | 术附汤去术 |
| **术附汤** | 白术附子汤 | 风湿相搏骨节烦疼(表阳中) | 术附汤本方用术一两二钱、附六钱 + 甘草姜枣 |
| **术附汤** | 甘草附子汤 | 风湿大便坚,小便自利(表阳轻) | 术附汤本方用术附各六钱 + 桂枝一两二钱 + 甘草 |
| **麻黄汤** | 麻黄杏仁薏苡甘草汤 | 风湿一身尽痛,日晡所剧(表实) | 麻黄汤加薏苡仁(去桂枝) |
| **防己黄汤** | (祖方本身) | 风湿相搏(表虚汗出恶风) | 黄 + 白术 + 防己 + 甘草姜枣 |

5 个方 = **5 种治风湿思路**(从表实到表虚,从表阳轻到重):
- 麻黄汤系:表实(脉浮紧,发热无汗)
- 术附汤系:表阳虚(脉沉细,汗出恶风)
- 防己黄汤系:表虚湿重(脉浮缓,汗出恶风,身重浮肿)

## 6. 临床一句话心法

**「白术附子汤」是术附汤家族的「中阶变法方」**,位于「桂枝附子汤(表阳重) → 白术附子汤(表阳中) → 甘草附子汤(表阳轻)」的**中段**,对应**风湿相搏骨节烦疼**的主证。

**临床选用流程图**:

```
风湿骨节痛(汗出恶风,脉沉细)
  ├─ 不能转侧(表阳重) → 桂枝附子汤(术附汤去术)
  │
  ├─ 掣痛不得屈伸 + 小便不利 + 身微肿(表阳中)
  │   → ★ 白术附子汤 ★
  │      术附汤本方用术一两二钱、附六钱
  │      + 甘草六钱、生姜一两、大枣十二枚
  │
  └─ 大便坚、小便自利(表阳轻,湿已入里)
      → 甘草附子汤(术附汤本方 + 桂枝、甘草)
      
失治 → 湿从寒化 → 水湿内停
  → 真武汤(术附汤本方 + 茯苓、芍药、生姜)
```
