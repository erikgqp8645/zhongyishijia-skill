# TCM 现代病名 → 古籍病名 扩展手册(口腔溃疡/针灸专题蒸馏实战固化)

> **来源**:2026-08-27 zhongyishijia 会话「口腔溃疡的针灸方剂查询」深度蒸馏
> **核心痛点**:中医世家数据库是 2012-2014 年离线数据,**几乎不含现代医学病名**(「口腔溃疡」「复发性口腔溃疡」「白塞氏综合征」均 0 命中);必须先扩展为古籍术语再查
> **实战证据**:扩展前 symptom_query.py "口腔溃疡" → 5 张;扩展后用 OR 「口疮/口糜/舌疮/鹅口疮/口舌生疮」→ 250+ 张方剂 + 60+ 首穴位贴敷方

### Step 3:多 OR 模式查询 + 双源取证

**入口 A**(症状库):
```bash
python scripts/symptom_query.py "口疮" --top 15
python scripts/symptom_query.py "口糜" --top 15
# (合并去重 → 250+ 张)
```

**入口 B**(古籍理论库,直查 SQL):
```python
import sqlite3
conn = sqlite3.connect('references/external/zysj.db')
# 不设 text_factory,见 sqlite_deployment_recipe.md § 陷阱 #3

terms = ["口疮", "口糜", "舌疮", "鹅口疮", "口舌生疮"]
filter_sql = " OR ".join([f"NeiRong LIKE '%{t}%'" for t in terms])
q = f"SELECT ID, BiaoTi, NeiRong FROM zysjllsj WHERE {filter_sql} LIMIT 100"

for r in conn.execute(q):
    title = r[1]  # sqlite3 默认 utf-8 解码(zysjllsj=UTF-8)
    content = r[2]
    print(f"\nID:{r[0]} | {title[:60]}\n{content[:300]}")
```

**入口 C**(方剂库,直查 SQL):
```python
# zysjyj=GBK 编码,需 dec_yj 函数
def dec_yj(v):
    if v is None: return None
    return v.decode('gbk', errors='replace') if isinstance(v, bytes) else v

cur = conn.execute(f"""
    SELECT MingCheng, ChuChu, GongNengZZ, ChuFang, YongFaYL FROM zysjyj
    WHERE GongNengZZ LIKE '%口疮%' OR GongNengZZ LIKE '%口糜%'
       OR GongNengZZ LIKE '%口腔%' OR GongNengZZ LIKE '%舌疮%'
    LIMIT 50
""")
for r in cur:
    print(f"\n方名: {dec_yj(r[0])}\n  主治: {dec_yj(r[2])[:200]}")
```

## 四、口疮专题·针灸 vs 方剂 的发现模式

### 4.1 「口腔溃疡」= 穴位贴敷 > 针刺(本次深度蒸馏核心洞察)

中医世家 zysjyj 库 30+ 首「含针/灸/穴位」口疮方剂中:

- **穴位贴敷类(60%+)**:涌泉/脚心/手足心/脐部贴敷吴茱萸/附子/天南星/草乌
- **远近端针刺类(< 20%)**:合谷/地仓/承浆/颊车/劳宫
- **灸法类(< 10%)**:涌泉/承浆灸法

**临床实证**:
- 吴茱萸+附子醋调贴涌泉:治鹅口疮 170 例,**有效率 98%**
- 草乌+南星+生姜醋调贴手足心:**「来日便愈」**
- 三颗针治口腔炎 34 例,**全部治愈**

**结论**:中医世家库里,「口腔溃疡」的针灸外治核心是**穴位贴敷**(吴茱萸粉/附子粉/天南星/草乌等辛热药醋调)→ **引火下行**,而非传统教科书上的针刺。

### 4.2 检索式扩展

不能只查 `针灸 + 口疮`,要查:
- `针灸 + 穴位 + 口疮`(传统针刺)
- `贴敷 + 涌泉/脚心/手足心 + 口疮/鹅口`(穴位贴敷主流)
- `吴茱萸 + 醋 + 口疮`(虚火引火下行特效)
- `狐惑 + 针灸 + 黄连犀角汤`(白塞氏综合征)
