## 一、原方对照

| 项目 | 茯苓杏仁甘草汤 | 橘枳姜汤(亦名橘皮枳实生姜汤) |
|:--|:--|:--|
| 组成 | 茯苓三两 / 杏仁五十个 / 甘草一两 | 橘皮一斤 / 枳实三两 / 生姜半斤 |
| 煎服法 | 以水一斗,煮取五升,温服一升,日三服。不瘥,更服 | 以水五升,煮取二升,分温再服 |
| 病机 | 湿气上逆、肺气滞 | 寒气上逆、胃气痞 |
| 三焦 | 手太阴肺(上焦) | 足阳明胃(中焦) |
| 药性 | 甘淡(茯苓利水) + 苦温(杏仁下气) | 辛温(橘皮生姜散寒) + 苦泄(枳实消满) |
| 异名 | 《千金》名"茯苓汤" | 《外台》作"橘皮枳实汤";《千金》无方名 |

## 六、心法

**两方并列治一证,核心辨是水(稀饮)还是气(痞塞)——水走茯苓汤,气走橘枳汤。**

- **核心辨证点**:短气为主 → 茯苓汤;胸中气塞为主 → 橘枳汤
- **本草新解**:杏仁不是"散结"而是"下气"(周岩、黄元御),这个解释跟吉益东洞"反方对应"逻辑高度自洽
- **日本考证派质疑**:吉益东洞直接质疑"二方治一证,非古之道";但中方主流(沈明宗、魏荔彤、何梦瑶、陈修园)一致认同"水气分治"
- **临床合方**:周士祢把两方合为"茯杏甘橘枳姜汤"六味,治小儿咳喘虚极咯血 — 这个问题提示"两方合用"在儿科是真实需求
- **现代应用**:陈可冀治冠心病有痰浊者,"两方都加" — 现代临床并不强分水气,而是按"湿+痞"复合病机共用
