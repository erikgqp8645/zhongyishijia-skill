# 方剂元数据表格（出处/作者/朝代/主治）

## 用途

当用户问"含 X 药方剂的出处/作者/成书年代/主治"时，使用 `scripts/formula_table.py` 一次性输出 Markdown 表格。

## 完整工作流

```bash
cd ~/.hermes/skills/zhongyishijia-expert-mentor-lineage

# 1. 含某药方剂的元数据表 (方名 / 朝代 / 出处 / 作者 / 主治)
python3 scripts/formula_table.py 细辛 --top 15
python3 scripts/formula_table.py 麻黄 --top 30
python3 scripts/formula_table.py 附子 --top 15

# 2. 输出 Markdown 表格，可直接嵌入回答
# | # | 方名 | 朝代 | 出处 | 作者 | 主治 |
# | 4 | 《千金》补肾丸 | 唐 | 《千金要方》 | 孙思邈 | 劳聋、气聋、风聋、虚聋、毒聋、久聋耳鸣者 |
```

## 数据来源

- **方剂名/出处/作者/朝代**：`zysjllsj` 表的 `BiaoTi`（章节标题）+ 启发式字典（`TITLE_HEURISTIC`）
- **主治**：`zysjllsj` 表的 `NeiRong`（章节正文）— 用正则提取"治X" / "此方主之X" / "《X》云∶Y" 句
- **过滤规则**：`_is_formula_title()` 排除"1.石膏"（药名章节）/"1.9 肛管"（学科章节）/"3.5 脂类"（数字.数字型）

## 已知局限（数据库限制）

1. **方名启发式字典覆盖 ~10% 的方剂出处**（只识别带"《书名》"或"伤寒/金匮/千金/外台"等标记的方名）
2. **纯名方"麻黄汤/小青龙汤"在 DB 里不以短名作为章节标题**（实际是"3．太阳病麻黄汤证"等方论章节），需 `--top 100` 才能看到
3. **"四逆汤"在 DB 里没有独立章节**（只有"附子四逆汤"变方），这是 DB 真实情况
4. **约 30% 的方剂"主治"显示"(未提取)"** — 因为章节正文里没有"治X"句型（只有方解/方论）

## 5 步开发中的踩坑经验

### 坑 1：字段名一致性
- `zysjllsj` 表叫 `BiaoTi`/`NeiRong`（不是 zysjyj 的 `MingCheng`/`ChuFang`）
- 查询方剂元数据必须用 `zysjllsj`，不能错用 `zysjyj`

### 坑 2：方名过滤 - 数字编号章节
- 章节标题可能带"1."或"3."数字编号（zysj.com.cn 网站内部编号）
- 用 ASCII 短词匹配 `^\d+[\.．]\s*[A-Za-z0-9]{1,6}$` 排除
- 但**不能**用 `\S{1,6}` 中文匹配（会误伤"3. 太阳病麻黄汤证"）

### 坑 3：方名过滤 - 单味药名
- "1.石膏"/"2.知母"等是纯药名章节，不是方剂
- 用白名单 `single_herbs = {石膏, 细辛, 麻黄, ...}` 排除
- 短标题（≤2 字）通常不是方剂

### 坑 4：本科正文提取正则
- 早期正则 `[^。；\n]{2,80}?(?=[。；\n]|$)` 只截到第一个句号，丢失"破癥坚积聚"
- 改为贪婪到下一个 `《X》` 引用标记 + 要求"主"字开头
- 多个分隔符（句号/分号/逗号/顿号）都需作为结束符

### 坑 5：中文长度计算
- Python `len("喉痹")` = 2（按字符数，不是字节数）
- 主治提取最小长度阈值要用 `>= 2`（不是 `>= 3`），否则"喉痹""中风"等 2 字主治被过滤

## 与 verify_prescription.py 的区别

| 脚本 | 数据源 | 输出 | 适用场景 |
|---|---|---|---|
| `verify_prescription.py` | `zysjyj` (方剂库) | 高频药条形图 + 本草原文 | "X 病用什么药" / "X 药的本经" |
| `formula_table.py` | `zysjllsj` (临床理论库) | 方名+朝代+出处+作者+主治 表格 | "含 X 药方剂的出处/年代/主治" |
| `query_formula.py` | `evidence_cards.jsonl` (蒸馏卡) | 朝代排序的医家论述汇总 | "X 方的历代医家论述" |

三个脚本不互斥，可以组合用：先用 `formula_table.py` 看含 X 药方剂的全表，再用 `verify_prescription.py` 看某个方剂的核心药 + 本草。
